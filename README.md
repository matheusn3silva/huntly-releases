# Huntly: downloads

Aqui ficam os **instaladores** do Huntly. O código do programa fica em outro repositório, privado.

## Baixar

Abra **[Releases](../../releases/latest)** e baixe o arquivo da versão mais nova, em *Assets*:

| Sistema | Arquivo |
| --- | --- |
| Windows 10/11 (64 bits) | `Huntly-Setup-<versão>.exe` |

## Instalar no Windows

1. Abra o `Huntly-Setup-<versão>.exe`.
2. Se o Windows mostrar **"O Windows protegeu o computador"**, clique em **Mais informações → Executar assim mesmo**. O aviso aparece porque o instalador ainda não tem assinatura digital.
3. Siga o instalador. Dá para escolher a pasta e se o Huntly abre com o Windows; não precisa de administrador.
4. O Huntly fica em segundo plano, com um ícone perto do relógio: clique duplo abre o app, e o botão direito tem **Sair**.

## Atualizar

Baixe e rode o instalador da versão nova por cima da atual. Os seus dados (configurações, currículos, candidaturas) ficam em `%LOCALAPPDATA%\Huntly` e **não são apagados** ao atualizar nem ao desinstalar.

O Huntly também avisa dentro do app quando houver versão nova.
